## The entry

Exactly one emoji — the hugging face 🤗 — the one most likely to make a stranger smile.

Why this one, against the judge's brief (a warmth judge reading a single emoji the way a stranger glancing at a phone screen would):

- **Warm and friendly at first glance** — open arms and a smile read as an offer of warmth with no context needed.
- **Universality** — a hug is understood the same way by a stranger of any age or background, with no irony or in-joke.
- **Chosen, not default** — a specific, deliberate pick, not the first plain smiley that comes to mind.
- **Right for a stranger** — friendly, not flirty, intimate or sarcastic, so it reads fine coming from someone unknown. (A hearts-face would risk reading as affection from a stranger; a plain smiley would read as the default.)

## How it works

`main.py` (Python standard library only) writes exactly that one emoji — no newline, no extra text — to `/output/entry.txt`, and verifies the file on disk holds exactly that emoji.

```sh
python3 main.py
```
